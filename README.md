# fpga-audio-spectrum-analyzer
本项目是一种高速实时音频频谱分析系统：以 Xilinx Artix-7（XC7A35T）FPGA 为核心，配合 ES8388 音频编解码与 5 寸 TFT 屏，将声音采集、加窗、1024 点 FFT、后处理与显示渲染五级在 168MHz 时钟下全流水并行执行，帧率达 93.7 帧/秒、端到端延迟低于 11ms、频率测量误差小于 0.5%、动态范围优于 60dB。采用基-2² SDF 流水线 FFT 架构与 FPGA 内置轻量图形引擎直接生成 RGB 像素流，无需 CPU 与帧存，整机手持一体化、可独立运行，广泛适用于音频可视化与信号分析场景。
